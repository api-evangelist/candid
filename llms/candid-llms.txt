# Candid's API Developer Portal Documentation

> Candid's APIs and datasets allow users to access comprehensive, high-quality data about nonprofits, grants and news. Candid's developer portal, developer.candid.org, is a resource for developers supporting the social sector to discover, learn, test, and implement Candid's nonprofit data API. Also known as: GuideStar API, Essentials API, Search API, Profile API, Premier API, Charity Check API, Candid data, Candid datasets, Custom datasets, Snowflake Nonprofit Datasets
